# Clawd 桌宠 🧡

一只纯粹为了可爱的像素 Clawd。没有任何功能,只负责在你的桌面上走来走去、犯傻、卖萌。

## 怎么玩(Windows)
1. 解压整个文件夹(不要直接在压缩包里运行)。
2. 双击 **Clawd.exe**。它会从天上掉下来跟你打招呼,托盘(右下角小图标)里可以退出。
3. 第一次运行如果 Windows 弹出"SmartScreen / 未知发布者",点 **更多信息 → 仍要运行**(这是个没花钱买证书的个人小程序)。

托盘右键菜单:召唤 / 哄睡 / 叫醒 / 跳舞 / 和 Clawd 说话 / 内置剧场 / 结束剧情 / 大模型设置 / 大小 / 气泡开关 / 感知软件开关 / 开机自启 / 退出。右键点 Clawd 本体也能直接打开聊天框。

## 它会做什么
- **站在所有窗口的顶边和下沿上**:在窗口标题栏上散步、站在窗口的底边上、在窗口之间跳上跳下、坐在边缘晃腿、走过头掉下去。窗口被你拖走,它会跟着一起走(或者摔下去)。
- **全屏时自动躲起来**(看视频 / 玩游戏 / 放 PPT 不挡你)。
- 30 多种小动作:走、跑、坐、睡觉、伸懒腰、挥手、跳舞、转圈、后空翻、看书、喝咖啡、吃饼干、敲笔记本(Claude Code 风格的 ✻ Cogitating…)、打嗝、打喷嚏、月球漫步、牵气球/拿小花、踢球、鞠躬……
- **鼠标互动**
  - 眼睛会跟着你的鼠标;你一直动鼠标,它会跟过来、扑过来抓;你猛冲过来它会吓一跳。
  - **摸它**(鼠标在它身上来回晃)→ 害羞冒爱心;摸够了 → 爱心眼。
  - **点击**它;**戳小短腿**会痒;**戳眼睛**会哭;**双击**后空翻。
  - **按住拖起来**会乱蹬腿,**扔出去**会弹跳 / 撞墙 / 摔晕。
  - 长按不动会呼噜。
- **彩蛋**(不剧透,自己找 😉):连点、绕圈圈、猛晃、深夜、整点、饭点、节日、还有极小概率出现的……✨



## 1.4 新增:像素道具库 · 自己设计像素道具 · 走钢丝 / 抓着气球飞 / 蹦到屏幕顶
之前模型只能放 emoji、只能在窗口上走。现在:
- **内置像素道具库**(40 个手绘像素图:热气球、云、太阳、梯子、宝箱、火箭、飞碟、蹦床、篝火……),模型按名字调用;
- **模型自己设计像素道具**:用字符画 + 调色板,一出戏最多 8 个,有严格校验(最大 24×24、最多 12 种颜色);
- **凭空造平台**:钢丝 / 木板 / 云 / 石台 / 冰块 / 钢梁,Clawd 可以站上去、走过去(走钢丝时会张开手臂保持平衡、冒汗),拆掉平台它会掉下来;
- **飞行**:抓着气球飞到屏幕顶、飞到右边、缓缓降落;**大跳**:想跳多高就跳多高,一口气蹦到屏幕顶,还能跳到指定平台上;
- **道具能带着走**:顶在头上 / 拿在手里 / 背在身后 / 举着气球牵绳;还能悬在半空(云、太阳、星星)并带动画(晃、转、飘);
- 故事结束时平台和道具自动清场,不会留在你的桌面上。
- 新增内置剧场:**马戏团**(走钢丝 / 热气球 / 蹦到顶,不需要 Key)。

试试对它说:`演一出走钢丝`、`抓着热气球飞上天`、`演一出外星人来访,要有飞碟`。

## 1.3 新增:边写边演 · 更复杂的剧情 · 二维追鼠标 · 更多能踩的地方
- **DeepSeek 对话体验修复**:新版 DeepSeek 默认开着"思考模式",思考内容会吃掉输出额度,导致剧本被截断、"没加载好就退出"。现在默认关闭思考模式,并改成**流式输出——写出一个节点就演一个节点**,通常 1~2 秒就开演,不用等整段写完。网络中途断了,也会把已经写好的部分演完再优雅收场。旧模型名 `deepseek-chat` 已被 DeepSeek 下线,会自动换成 `deepseek-flash`。
- **回答窗口不再误关**:剧情里问你问题(打字回答)的小窗口,失焦也不会关,还多了"跳过"按钮;聊天窗口在等待回答时也不会因为失焦被关掉。
- **剧情表达力大幅提升**(上限从 24 个节点放宽到 160 个,单次输出默认 8000 token,设置里可调到 3 万;每日额度默认 60 次 / 60 万 token):新增 变量(`set`)、条件(`if`)、随机分支(`random`)、循环(`loop`)、多个道具(`item` + `take` / `put`)、换装(`wear`)、屏幕氛围色(`tint`)、更多特效(雪 / 雨 / 烟花 / 泡泡 / ❓❗💢…)、台词里带表情姿势、边说边做动作;等待的事件也更多(鼠标悬停 / 不动 / 乱动 / 去屏幕某一边 / 在打字 / 把它拎起来…);最多续写 8 段。
- **二维追鼠标**:躲猫猫等剧情里,Clawd 会把所有窗口当成一张"地图",**x 和 y 都朝鼠标靠近**:该跳上去就跳上去,该跳下来就跳下来,到了鼠标下面还会扑一下。剧情里还能让它"跳到更高/更低/别的窗口上"。
- **更多能踩的地方**:窗口的**下沿**(站在窗口底边上);装了新版浏览器插件后,网页元素的**下沿**也能踩(插件请在 `chrome://extensions` 里点一下"重新加载")。
- 新增内置剧场:**海盗寻宝**(无需 Key,演示了换装、窗口间探险、变量和多个结局)。

## 1.2 新增:和它说话 · 互动剧场 · 自创动作(可选接入 DeepSeek)
**不填 Key 也能玩**:右键点它(或托盘 →"和 Clawd 说话"),里面有 5 个**内置互动剧场**(寻找饼干 / 躲猫猫 / 海盗寻宝 / 马戏团 / 晚安小剧场),完全离线。

**填了 Key 之后**(托盘 →"大模型设置",或聊天框右上角 ⚙):你可以直接对它说——
- `演一出海盗寻宝` → 大模型当编剧,写一出**可以和你互动的小剧场**:Clawd 会走、跳、自创表情和动作、放出道具(🍪💎🦋…),并且会
  - 给你**选项按钮**让你决定剧情走向;
  - 等你**摸它 / 点它 / 挠它的腿 / 靠近 / 离开 / 把它扔出去**,再接着演;
  - 问你问题,让你**打字回答**,之后的台词会用你的回答;
  - 演到一半**暂停,等你互动后再续写下一段**(最多 8 段)。
- `学个害羞转圈的动作` → 它**发明一个新动作**,先演给你看,你点"收下"才会存进"动作书",以后会偶尔自己表演。
- `陪我聊两句` → 它用一句话回答。
- 快捷写法:`/演 …`、`/学 …`、`/聊 …`。

**怎么做到省 token**:固定的短系统提示(DeepSeek 对重复前缀自动缓存)+ 只发一行摘要(性格 / 认识天数 / 心情 / 时段 / 可踩窗口个数)+ 每日次数和 token 上限(默认 60 次 / 60 万 token,可改);额度用完或断网,自动回到离线模式。复杂的长剧情一次大约几千 token。
**安全**:模型输出的只是 JSON 数据,必须通过白名单校验才会播放(只允许固定的节点类型、动作、数值范围,文字会被截断);**不执行模型生成的任何代码**。
**隐私**:只会发送你输入的话 + 那一行摘要,不发送窗口标题、文件、截图、你在用的软件。Key 只存本机,Windows 上用系统加密(DPAPI)保存,桌宠主画面读不到它。接口是通用的"OpenAI 兼容"格式,地址 / 模型都能改(默认 DeepSeek)。

## 1.1 新增:它更"活"了(全部离线,不需要任何 API Key)
- **性格**:每只 Clawd 第一次运行时会随机拥有两种性格(爱玩 / 嗜睡 / 好奇 / 黏人),会影响它爱做的事。你的 Clawd 和别人的不一样。
- **情绪**:有心情、精力、无聊、孤独。精力低了会犯困打瞌睡、眼神迷糊;很久没人理它会有点失落;无聊了会自己找乐子;心情好会更爱跳舞。
- **记忆**:记得认识了几天、摸了几次、上次什么时候来(只存在本机的 `memory.json`)。久别重逢、连续陪伴、纪念日都有专属台词;摸 50 次、戳 300 次、认识 100 天会解锁蝴蝶结 / 墨镜 / 皇冠。
- **陪你,不吵你**:能分辨你是在**打字**(键盘也算)还是在发呆。你打字时它会安静地在旁边敲小笔记本、看书、喝咖啡;你离开很久它会睡着,你一回来它会醒来迎接。
- **看得见你在用什么**(可选,默认开,托盘里可关):只在本机读取"当前软件的进程名",不读标题和内容,不上传、不保存。写代码时给你加油,开终端它也去敲键盘,放音乐它跳舞,看视频它陪你……
- **新的小故事**:追蝴蝶(它会落在它头上)、盯着地上的小虫子准备扑、走路绊倒后假装没事、坐着打瞌睡、新窗口弹出来会好奇地看、**你拖动它脚下的窗口它会"冲浪"**。
- **节日**:春节、中秋、国庆、儿童节、情人节、圣诞、万圣节、元旦。
- 更丝滑:跟着窗口移动、跟着网页滚动时更平滑。

> 隐私:全程不联网(只和你本机浏览器插件通信)。记忆文件在 `%APPDATA%\clawd-pet\memory.json`,删掉它就等于"重新认识"。

## 让它在网页的 `<div>` 上走(可选)
桌面程序本身看不到网页里的元素,所以需要装一个很小的浏览器插件,它只会把"元素的位置"发给本机的 Clawd(`127.0.0.1:23333`),不读取、不上传任何页面内容:

1. Chrome / Edge 打开 `chrome://extensions`(Edge 是 `edge://extensions`),打开右上角 **开发者模式**。
2. 点 **加载已解压的扩展程序**,选择本文件夹里的 `browser-extension` 目录(托盘菜单"浏览器插件"也能直接打开它)。
3. 打开任意网页,Clawd 就能走在卡片、图片、按钮、导航栏上了。滚动页面它会跟着元素走。

> 位置是估算出来的(浏览器没有提供精确的屏幕坐标),所以可能差几个像素,看起来像"飘"在边上或陷进去一点点,属于可爱范围内 :)
> 页面缩放、多显示器、非主屏上的浏览器可能偏差更大。

## 从源码运行 / 自己打包
```bash
npm install
npm start                 # 直接运行
npm run dist              # 打 Windows 包(zip)
```
需要 Node.js 18+。源码很短:`main.js`(窗口/托盘/窗口枚举)、`renderer/rig.js`(像素画)、`renderer/brain.js`(行为与互动)。

## 已知限制
- 目前只支持**主显示器**。
- 窗口检测靠 PowerShell(Windows 自带)。如果公司电脑禁用了 PowerShell,它仍然可以在任务栏上玩,只是不能站在窗口上。
- Clawd 是 Anthropic 的吉祥物,这是粉丝自制的小玩意,与 Anthropic 无关。

## 更新(不用重新下载 100MB)
完整包大部分体积是 Electron 内核,而 Clawd 自己的代码只有几十 KB。所以每次更新只需要**轻量更新包 `Clawd-update-vX.Y.Z.zip`**(几十 KB):
1. 把它解压到你的 Clawd 文件夹里(和 `Clawd.exe` 放一起)。
2. 双击 `update.bat`,它会关闭 Clawd → 替换 `resources\app.asar` → 重新启动。你的"记忆"不会丢。

自己打更新包:`npm run dist && python scripts/make_update.py`。

## 开发
```bash
npm install
npm start               # 运行
npm run icon            # 重新生成 build/icon.png
npm run dist            # 打包(zip);在 Windows 上打包会带上自己的 exe 图标
python scripts/make_update.py   # 生成轻量更新包
```
目录:`main.js`(窗口 / 托盘 / 窗口枚举 / 本地服务 / 聊天与设置窗口)、`llm.js`(大模型客户端与提示词)、`preload.js`、`renderer/script.js`(剧本格式与安全校验)、`renderer/director.js`(剧本播放器)、`renderer/stories.js`(内置剧场)、`renderer/chat.*` `renderer/settings.*`(聊天与设置界面)、`renderer/rig.js`(像素画)、`renderer/life.js`(性格 / 情绪 / 记忆 / 台词 / 节日)、`renderer/brain.js`(物理 / 行为 / 互动)、`browser-extension/`(网页地面插件)。

推送形如 `v1.1.0` 的 tag 会触发 GitHub Actions,在 Windows 上自动打包并发布到 Release(完整包 + 轻量更新包)。
